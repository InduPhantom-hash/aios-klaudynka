# Referencje analizy danych

- Zawsze nazwij grain przed agregacją i sprawdź kardynalność przed joinem.
- „Udział w obserwowanych zdarzeniach” nie jest rate’em bez pełnego mianownika.
- Dla dużych plików lub wielu źródeł użyj narzędzia analitycznego zdolnego do SQL; raport ma pokazać tylko dane potrzebne do decyzji.
- Wykres jest dowodem pomocniczym: opisuj jednostkę, populację, okres oraz ograniczenia.
