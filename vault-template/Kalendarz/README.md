# Kalendarz

Daily notes, weekly reviews, deadliny. Struktura minimalna - init może dopisać więcej na podstawie Sekcji G (rytm pracy).

## Sugerowane

```
Kalendarz/
├── daily/          ← YYYY-MM-DD.md (jeśli robisz daily)
├── weekly/         ← YYYY-WW.md (jeśli robisz weekly review)
└── deadliny.md     ← lista terminów (opcjonalnie)
```

Nic obowiązkowego - jeśli nie robisz daily/weekly, zostaw pusty folder.

---

*`/aios:init` Sekcja G - Rytm pracy - może zaproponować konkretną strukturę na podstawie Twoich nawyków.*
