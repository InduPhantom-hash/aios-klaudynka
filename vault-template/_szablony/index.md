# Indeks Szablonów AIOS (`_szablony/`)

Globalne szablony dokumentów stosowane w vaulcie przez użytkownika oraz skille AIOS.

- [zadania.md](file:///zadania.md) - szablon aktywnego trackera zadań dla projektu (AIOS Task Tracker).
- [brief-projektu.md](file:///brief-projektu.md) - uniwersalny brief nowego projektu tworzony przy `/aios:stworz-projekt`.
- [decyzja.md](file:///decyzja.md) - szablon zapisu decyzji architektonicznych i biznesowych do `decyzje.md`.
