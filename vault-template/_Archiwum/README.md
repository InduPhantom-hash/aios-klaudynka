# _Archiwum

Martwe gałęzie. Projekty które utknęły, wątki które nie poszły, dead-endy z `_brudnopis/`.

## Struktura

```
_Archiwum/
├── dead-ends/          ← wątki z _brudnopis/ które nie poszły nigdzie
│   └── YYYY-MM-DD-slug/
│       └── reason.md   ← dlaczego dead-end
└── projekty/           ← przeniesione nieaktywne projekty
    └── <nazwa>/        ← pełna struktura z README, decyzje itd.
```

## Zasady

- `_Archiwum/` nie trafia do Pinecone ani standardowych wyszukiwań.
- `/aios:szukaj` sięga tutaj tylko gdy user explicite prosi ("szukaj też w archiwum").
- Przenosiny do archiwum są **decyzją użytkownika** - żaden skill nie robi tego automatycznie.

*Archiwum to nie kosz - to historia. `Kosz/` jest na rzeczy do ostatecznego usunięcia.*
